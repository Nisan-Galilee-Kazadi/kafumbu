🚀 DÉMARRAGE RAPIDE

1. Importer le schéma BD:
   mysql -u root -p kafumbu_smartcity < database_schema.sql

2. Installer et lancer le backend:
   cd server && npm install && npm run dev
   → API sur http://localhost:4000

3. Dans un nouveau terminal, lancer le frontend:
   npm install && npm run dev
   → Frontend sur http://localhost:5173

4. Accéder au dashboard:
   Allez à http://localhost:5173/admin
   Connectez-vous: admin@kafumbu-smartcity.cd / Admin@123
